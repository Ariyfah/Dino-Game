# Dino Runner Game in Logisim Evolution
Chrome Dino inspired game built using Logisim Evolution.


## Features

- LED Matrix Display (32x16)
- Jump Button Control
- Live Score Tracking
- High Score Memory
- Collision Detection
- On, Off and Start Controls
  
## How to Run

1. Install Logisim Evolution.
2. Download 'DinoGame.circ'.
3. Open the file in Logisim Evolution.
4. Use the Start button to begin the game.

## Notes
- The game requires the clock to be running (Auto Tick Enabled).
- Set the tick frequency to at least 32 Hz for proper gameplay.
- Press the On button then the Start button to begin.
- Use the Jump button to avoid cactus.
