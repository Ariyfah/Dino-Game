# Dino Runner Game in Logisim Evolution
Chrome Dino inspired game built using Logisim Evolution.

<img width="2381" height="1122" alt="Dino Game-Poster" src="https://github.com/user-attachments/assets/2bcea1bf-b07d-40f6-85cb-ad3365fc91d2" />


## Features

- LED Matrix Display (32x16)
- Jump Button Control
- Live Score Tracking
- High Score Memory
- Collision Detection
- On, Off and Start Controls
